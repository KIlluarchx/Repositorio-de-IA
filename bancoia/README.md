# Banco de IA para Investigación

Herramienta interactiva con tabla de recursos e inteligencia artificial aplicados a la investigación.

## Vista previa y despliegue

Este proyecto es una aplicación web estática (`index.html`) lista para ser desplegada en **GitHub Pages**:

1. Sube este repositorio a tu cuenta de GitHub.
2. Ve a **Settings** > **Pages**.
3. En **Source**, selecciona `Deploy from a branch`.
4. Elige la rama `main` y la carpeta `/(root)`.
5. Guarda los cambios. Tu sitio estará disponible en `https://<tu-usuario>.github.io/<nombre-repo>/`.

## Estructura

- `index.html`: Aplicación completa (HTML, CSS y JavaScript integrados).
