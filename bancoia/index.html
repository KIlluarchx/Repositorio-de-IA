Cómo leer este banco

El tipo de acceso es orientativo: gratis, freemium (plan gratuito limitado), de pago o institucional (requiere suscripción de la universidad). Los planes y precios cambian con frecuencia; verifícalos en la web de cada herramienta.

La etiqueta Uso ético marca herramientas que pueden usarse para ocultar plagio o texto generado por IA. Las normas ICMJE, COPE y WAME exigen declarar el uso de IA y prohíben atribuirle autoría.
